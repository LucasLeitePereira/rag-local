# Onboarding de novos desenvolvedores

Passos para começar a contribuir com o projeto.

## Acesso

Peça acesso ao repositório e ao workspace do Slack ao seu gestor direto. O acesso ao banco de produção é liberado somente após 30 dias, por segurança.

## Primeiro deploy

Todo novo desenvolvedor faz um deploy de uma mudança trivial (como corrigir um typo) no primeiro dia, guiado por um par, para conhecer o pipeline de CI/CD na prática.

## Referências

Leia `docs/ARQUITETURA.md` antes de mexer em qualquer parte do sistema de autenticação ou de cobrança — são as áreas com mais decisões não óbvias.
